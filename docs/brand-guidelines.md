# Identité de La Table d’Arçins

Référence fournie : https://latabledarcins.com/ ; logo et polices fournis par le propriétaire.

- Nom affiché : **La Table d’Arçins**, comme sur le site officiel.
- Rouge principal : **#D22329**, relevé dans la feuille de style du site.
- Noir : **#1E1E1E** ; surfaces blanches, gris neutres secondaires.
- Titres : **Louda Regular SC** ; corps et formulaires : **Avenir Book**.
- Logo : fichier original fourni, proportions conservées, sans redessin ni recoloration.
- Interface métier sobre : tableau directement utilisable, accents rouges réservés aux actions et à la navigation, textes d'état explicites.
- Les tons sémantiques (succès, avertissement, refus) accompagnent toujours un libellé.
- Polices servies localement par Next.js, sans appel à Google Fonts.
- Les exemples sont explicitement fictifs ; aucun chiffre de performance inventé.
